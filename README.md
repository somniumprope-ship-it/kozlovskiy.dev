# kozlovskiy.dev

Портфолио с закреплённой левой колонкой и независимой правой сценой + админка, где всё это редактируется без кода.

Схема слотов и типографика — в [LAYOUT.md](LAYOUT.md). Тексты и картинки в репозитории — заглушки.

## Запуск для разработки

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173` (сайт) и `http://localhost:5173/admin` (админка).
Без настроек пароль админки в dev — `admin`.

## Админка (`/admin`)

- **Левая часть** — фото, текст о себе, часы, бегущая строка, карточки работ, почта и соцсети, меню и форма подписки (RU и EN рядом).
- **Правая часть** — перетаскиваете файлы (JPG, PNG, WebP, AVIF, GIF, SVG, MP4, WebM), задаёте порядок, подписи и ссылки.
  Видео играет без звука по кругу, поэтому это и есть «анимации». Плитки сами встают в три колонки по своим пропорциям.
- **Сайт** — название вкладки и акцентный цвет.

Нажмите «Сохранить» — изменения сразу видны на сайте. Файлы, на которые больше нет ссылок, сервер удаляет сам (не раньше чем через сутки после загрузки).

## Запуск на своём сервере

```bash
npm install
npm run build
ADMIN_PASSWORD='ваш-длинный-пароль' NODE_ENV=production npm start
```

Одного процесса достаточно: он отдаёт сайт, API и загруженные файлы. Все данные лежат в `./data`
(`content.json`, `uploads/`, `subscribers.jsonl`) — это единственное, что нужно бэкапить. Переменные — в [.env.example](.env.example).

- В production сервер **не запустится без `ADMIN_PASSWORD`**.
- Держите сайт за HTTPS (nginx/Caddy): токен админки передаётся в заголовке.
- Для nginx поднимите лимит загрузки: `client_max_body_size 200m;` — иначе большие видео упрутся в 413.
- Процесс удобно держать под `pm2` или `systemd`. После нового `npm run build` перезапускайте его.

## Как устроена независимость колонок

- Навигация и язык — состояние только левой части.
- `Stage` (правая часть) получает только `content.right` и обёрнут в `memo`: клики слева, смена языка и тики часов её не перерисовывают. Проверено: ни одной мутации DOM, скролл и видео не сбрасываются.
- Каждая колонка имеет свой экземпляр Lenis: колесо крутит ту, над которой курсор.
- Весь интерфейс в `rem`; на десктопе корневой размер шрифта подстраивается под экран
  (`src/index.css`), поэтому композиция целиком помещается в экран на MacBook, Full HD и 4K.
